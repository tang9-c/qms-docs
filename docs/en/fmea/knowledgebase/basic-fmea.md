# Basic FMEA

Basic FMEA is general module knowledge, containing highly reusable FMEA knowledge within the organization (such as general electrical modules, mechanical modules, etc.). This guide explains how to build and use Basic FMEA.

## Construction Steps

1. **Identify General Modules**: Analyze common, reusable product or process modules within the organization.
2. **Create Basic FMEA Projects**: Create dedicated Basic FMEA projects for each general module.
3. **Execute FMEA 7-Step Analysis and Release**: Compared to Application/Family FMEA, it skips the approval nodes and does not require approval.

## Application Method

Basic FMEA can be used as a template, referenced or copied when creating new FMEA projects, greatly improving analysis efficiency and consistency.
