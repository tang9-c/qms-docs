# Import/Export

The Import/Export feature supports two-way synchronization with Excel, allowing users to edit FMEA data in Excel and then import it into the system. This guide explains how to use the Import/Export feature.

## Excel Import/Export

Supports two-way synchronization with Excel (requires using standard template).

![Excel Import/Export](/images/wps66.png)

![Excel Import/Export Details](/images/wps67.png)

## Usage Notes

- Ensure using standard template before importing
- Exported data can be used for backup or offline analysis
- System will automatically validate data format and integrity during import
