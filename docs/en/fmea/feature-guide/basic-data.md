# Basic Data Configuration

Basic data configuration is the prerequisite for FMEA analysis, including product classification, product information, process/process library, function library, and scoring rules. This guide explains how to configure these basic data settings.

Product classification is the foundation for categorizing and managing products, facilitating subsequent FMEA analysis and statistics.

The process/process library and function library are commonly used basic libraries in FMEA analysis, containing standard process steps and function definitions.

Scoring rules define the evaluation standards for Severity (S), Occurrence (O), and Detection (D), ensuring consistency in team scoring.
