# FMEA Dashboard

FMEA dashboard is used to visually monitor FMEA project progress, failure mode statistics, and risk distribution. This guide explains how to use the FMEA dashboard.

## Dashboard Features

Visualize and monitor the following:
- FMEA Project Progress
- Failure Mode Statistics
- Risk Distribution

Default statistics show data from the last 30 days.
