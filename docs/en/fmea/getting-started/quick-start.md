# Quick Start

This guide will help you get started with the FMEA module, including first login and creating your first FMEA project.

## First Login

- **Administrator**: You will have full permissions including project creation, team management, and template settings.
- **Member**: You will be invited to specific projects and responsible for editing and reviewing corresponding sections.

## Create Your First FMEA Project

1. Click "New" in 「DFMEA/DFMEA Projects」 to create a new project.
2. Fill in basic project information (name, product/process, team).
3. Click "Submit and Initiate Decision".
