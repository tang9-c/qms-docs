# Core Interface Overview

This guide introduces the core interface elements of the FMEA module, helping you quickly familiarize yourself with the system's layout and features.

## Left Navigation Bar

The left navigation bar contains the following main modules:

- DFMEA Project List
- PFMEA Project List
- Experience Case Library
- Basic Database
- Score Settings

![Left Navigation Bar](/images/wps3.png)

## Main Work Area

The main work area is the core editing area for FMEA tables. You can perform Structure Analysis, Function Analysis, Failure Analysis, and other operations here.

## Top Function Button Area

The top function button area displays different function buttons based on the selected type, providing quick access to common operations.

![Top Function Button Area](/images/wps4.png)
