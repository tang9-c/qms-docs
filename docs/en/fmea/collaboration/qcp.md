# QCP

QCP (Quality Control Plan) transforms the product function requirements and key control measures defined in the released FMEA into executable instructions for production and inspection sites without omission or deviation. This guide explains how to use the QCP feature.

## QCP Features

QCP features can:
- Automatically extract key control measures from FMEA
- Transform into executable instructions for production and inspection sites
- Ensure information consistency and integrity
