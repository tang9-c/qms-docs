# 风险分析

风险分析是 FMEA 分析的第五步，目标是系统根据S、O、D值进行风险矩阵分析，识别高风险区域并确定优先级。本指南将介绍如何进行风险分析。

## 风险矩阵分析

- **目标**：系统根据S、O、D值进行风险矩阵分析，识别高风险区域并确定优先级。
- **角色**：风险分析角色成员
- **入口**：
  1. 首页/我的待办/待办
  2. 顶部菜单栏/风险矩阵分析
- **操作**：
  1. 对每个失效链，在表格中下拉选择 严重度(S)、频度(O)、探测度(D) 的评分（1-10）。
  2. 系统自动计算 措施优先级(AP)：高 (H)， 中 (M)， 低 (L)。
  3. 可视化：风险矩阵图实时显示所有失效点的分布。

## DVP（设计验证计划）

DVP 用于汇总在风险分析中优化探测措施的内容，通常由包含测试项目的名称、测试方法、样本量以及预期通过的标准构成。

## 风险改善对比

风险改善对比用于展示对**初始风险评估**（基于当前控制的严重度 S、频度 O、探测度 D 和 AP 评分）与**实施并验证优化措施后**得到的**新风险评分**进行平行展示，从而量化说明风险等级的降低程度及改进效果。
