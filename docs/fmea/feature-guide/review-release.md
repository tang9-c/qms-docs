# 评审与发布

评审与发布是 FMEA 分析的第七步，目标是智能团队评审通过后，汇总FMEA分析过程相关数据，生成报告。本指南将介绍如何进行评审与发布。

## 职能团队评审

风险分析完成后，【职能团队评审】角色成员需要对整个FMEA项目进行全面审查，并提交审批意见。

![职能团队评审](/images/wps50.png)

![职能团队评审详情](/images/wps51.png)

## 重要流程控制

所有【职能团队评审】角色成员都必须完成审批，仅有当所有评审成员都不同意后，项目才会最终发布，形成稳定的正式版本。

## 结果与文件化

评审团队审批通过：自动汇总表单并生成报告，一键导出标准格式的FMEA表格、风险矩阵图或措施跟踪表。
