# 优化措施

优化措施是 FMEA 分析的第六步，目标是制定措施，跟踪结果。本指南将介绍如何制定和管理优化措施。

## 制定优化措施

- **目标**：制定措施，跟踪结果。
- **操作**：
  - 对于高/中AP项：点击 "标记优化"

    ![标记优化](/images/wps47.png)

  - 在优化措施清单中，指定负责人和完成日期，发起任务

    ![指定负责人](/images/wps48.png)

  - 措施状态：待处理 -> 进行中 -> 已完成 -> 已验证。

## 重要流程控制

风险分析完成后，需要由【项目经理】角色成员提交评审，项目才会流转到【职能团队评审】节点。

![提交评审](/images/wps49.png)
