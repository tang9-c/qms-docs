# 基础数据配置

基础数据配置是 FMEA 分析的前提，包括产品分类、产品信息、工艺/工序库、功能库和评分规则等。本指南将介绍如何配置这些基础数据。

## 新增产品分类

产品分类是对产品进行归类管理的基础，便于后续的 FMEA 分析和统计。

![新增产品分类](/images/wps5.png)

## 新增产品信息

产品信息包含产品的详细属性和特征，为 FMEA 分析提供基础数据支持。

![新增产品信息](/images/wps6.png)

## 新增工艺/工序库、功能库等

工艺/工序库和功能库是 FMEA 分析中常用的基础库，包含了标准的工艺步骤和功能定义。

![新增工艺/工序库](/images/wps7.png)

## 编辑评分规则

评分规则定义了严重度(S)、发生度(O)和探测度(D)的评分标准，确保团队评分的一致性。

![编辑评分规则](/images/wps8.png)
