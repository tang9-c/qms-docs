# 变更管理

变更管理是确保所有FMEA文件（家族/项目）的内容与其所描述的产品设计、制造过程及实际风险保持同步的重要环节。本指南将介绍如何进行变更管理。

## 发起变更

任何项目成员都可以发起变更。

![发起变更](/images/wps54.png)

### 填写变更申请

![填写变更申请](/images/wps55.png)

![变更申请详情](/images/wps56.png)

点击"提交"，发起变更审批。

## 变更审批

![变更审批](/images/wps57.png)

![变更审批详情](/images/wps58.png)

同意变更申请后，项目团队可继续从结构分析开始编辑。

## 版本管理

变更发布后，会更新版本和记录历史版本。

![版本管理](/images/wps59.png)
