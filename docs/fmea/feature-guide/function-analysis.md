# 功能分析

功能分析是 FMEA 分析的第三步，目标是为每个结构元素定义其功能和要求。本指南将介绍如何进行功能分析。

## 功能定义

- **目标**：为每个结构元素定义其功能和要求。如果一个功能有多个要求，需创建多条记录。
- **角色**：实施中角色成员
- **操作**：
  - 选中一个结构元素，在右侧面板的"功能"栏点击 "+"。
  - 清晰描述"是什么"和"应做到什么"。
  - 示例：密封圈 -> 功能：在接口处提供防水密封；要求：承受至少 10 Bar 压力。

## 功能网

功能网是通过图形化的方式展示系统各层级要素之间的技术依赖关系的可视化工具。

当各层级的功能按照层级逻辑相互连接时，便形成了功能网络。它也是后续失效分析（失效网）的分析基础，在功能网络中的逻辑线会转化为默认失效链。
