# 结构分析

结构分析是 FMEA 分析的第二步，目标是定义分析范围，构建层级结构，构造分析的基础骨架。本指南将介绍如何进行结构分析。

## 层级结构

- **目标**：定义分析范围，构建层级结构，构造分析的基础骨架。
- **角色**：实施中角色成员
- **操作**：
  - 点击 "添加同级/添加下级"，从最高层级（系统）开始，逐级分解到最低层级（零件/工序要素）。
  - 拖拽元素可以调整层级关系。

## 边界图

边界图是一种用于定义分析的范围并识别系统与其环境及相邻系统之间的交互作用的可视化分析工具。

### 使用方法

- 使用**方块**代表产品的主要组件。
- 使用**实线**表示直接接触的接口，使用**虚线**表示间接接触（如间隙或相对运动）。
- 使用**箭头**表示交互的方向

### 接口/连接类型 (PEIM)

识别并标注组件之间流动的能量流、信号或力。主要分为四种类型：

- **P (Physical)**：物理连接（如焊接、螺栓紧固、夹紧等）
- **E (Energy)**：能量传递（如扭矩、热量、摩擦、电能等）
- **I (Information)**：信息传递（如 ECU 信号、传感器数据等）
- **M (Material exchange)**：物料交换（如冷却液、废气、润滑油等）
