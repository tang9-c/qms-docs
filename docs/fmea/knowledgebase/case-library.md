# 经验案例库

经验案例库是 FMEA 分析的重要知识库，用于存储和复用已完成的 FMEA 分析案例。本指南将介绍如何使用经验案例库。

## 加入案例库

当DFMEA项目完成并通过职能团队评审后，可将其加入经验案例库。案例库默认给组织内用户查看。

**步骤：**
1. 项目状态为"已完成/已更新"时，显示"加入案例库"按钮
2. 点击按钮，确认操作
3. 项目信息自动保存到案例库

![经验案例库](/images/wps64.png)

## 查看与复制

在经验案例菜单中浏览、搜索和复制已归档的FMEA案例。经验案例库默认向所有系统成员开放。

**菜单路径：**FMEA/FMEA/DFMEA/经验案例
