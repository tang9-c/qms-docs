# 常见问题

本页面汇总了 FMEA 分析中常见的问题和技巧，帮助您更好地使用 FMEA 模块。

## Q1：AP（措施优先级）高、中、低是什么意思？我该怎么做？

- **高(H)**：必须采取行动。团队需制定优化措施，并降低风险。
- **中(M)**：建议采取行动。团队应评估措施的可行性和成本效益。
- **低(L)**：无需额外措施。可接受当前风险，但需在控制计划中明确管控方法。

## Q2：如何确保团队评分的一致性？

- 使用内置的 "评分标准速查" 功能（点击表头"S/O/D"旁的?图标）。
- 管理员可在 "评分规则设置" 中根据公司规范自定义评分准则。

## Q3：FMEA和控制计划(CP)如何联动？

- 在PFMEA中确定的"预防措施"和"探测措施"，可一键 "传递至控制计划" 模块，确保信息一致，避免遗漏。
